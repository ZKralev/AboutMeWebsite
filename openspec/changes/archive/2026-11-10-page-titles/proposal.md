# Proposal

## Why
Every route shows the same tab title, which hurts navigation, history and SEO.

## What Changes
Set `document.title` per page: Home, My Stack, About Me, Experience.

## Capabilities
### New Capabilities
- `page-titles`: browser tab title reflects the current page.
### Modified Capabilities

## Impact
`src/Components/Pages/page.tsx` or each page component; `menu.json` titles reused.
